## 🚀 How to Deploy (Netlify Drop)
1. Go to [netlify.com](https://netlify.com) and sign in
2. Click **"Add new site" → "Deploy manually"**
3. Drag and drop this entire folder onto the page
4. Your site will be live in seconds!
